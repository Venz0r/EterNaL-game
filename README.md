ETERNAL — COSMIC AWAKENING 1.2
Автономная браузерная idle/collector RPG для Android и ПК.

УСТАНОВКА
1. Распакуйте архив полностью, сохранив папку assets рядом с index.html.
2. Откройте index.html в современном браузере (Chrome рекомендуется).
3. На Android можно открыть файл локально или разместить папку на статическом хостинге.
4. Не удаляйте данные браузера сайта, если хотите сохранить прогресс.

ОБНОВЛЕНИЕ 1.2
- Добавлены плавные idle-анимации героев: лёгкое парение, дыхание свечения и тень.
- Добавлена анимационная отдача в бою и визуальная подсветка стороны атаки/получения удара.
- В арене теперь отображаются портреты выбранных героев команды.
- Добавлен резонанс стихий: команда из трёх героев с тремя разными стихиями получает +6% к атаке и +4% к защите.
- Добавлен шанс активации фирменной техники одного из героев; бонус участвует в реальном расчёте победы и отражается в боевом журнале.
- Исправлен расчёт вероятностей призыва: веса теперь нормализуются по фактической сумме, а не по условным 100 пунктам.
- При призыве x10 показывается сводка по полученным редкостям.
- Обновлён раздел событий: обозначены направления развития, которые ещё не являются доступными режимами.
- Сохранены существующие герои, этапы, ресурсы, команда, созвездия, задания и ключ сохранения eternal_save.

ВАЖНО О СОХРАНЕНИЯХ
Игра продолжает использовать localStorage с ключом eternal_save. При обновлении заменяйте index.html и папку assets в прежней папке игры, не меняя её расположение; не очищайте данные сайта/браузера. Рекомендуется сохранить резервную копию старой папки.

ОГРАНИЧЕНИЯ
- Игра работает локально и не содержит аккаунтов, серверной синхронизации, рейтингов или сетевой игры.
- Анимации персонажей в этой версии — лёгкие CSS-анимации поверх имеющихся иллюстраций, а не покадровые боевые спрайты.
- На реальном Android-устройстве эта сборка не проходила физическое тестирование в рамках подготовки архива.


ETERNAL 1.3 — PWA & GAMEPLAY PATCH
- Исправлено повторное получение наград за один этап: после победы требуется перейти на следующий этап.
- Добавлена PWA-оболочка: manifest, иконка, Service Worker, офлайн-кэш и предложение установки.
- На HTTPS-хостинге (например, GitHub Pages) игра может устанавливаться на главный экран Android.
- Service Worker проверяет новую версию и показывает кнопку обновления; после подтверждения вкладка перезагружается.
- Сохранение eternal_save и существующая структура игровых данных не менялись.
ВАЖНО: PWA-установка и автообновления требуют HTTPS или localhost. Открытие index.html прямо из ZIP/файлового менеджера не поддерживает Service Worker.
